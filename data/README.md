# Data Folder

Эта папка содержит данные, используемые приложением Gemini Gateway, в основном для хранения шаблонов промтов и связанной с ними метаинформации.

## Структура папки

```
data/
  README.md
  prompts.json
  prompts/
    .gitignore
    example.txt
```

## Как заполнить эту папку

### 1. Добавьте файлы с текстами промтов

- Помещайте шаблоны промтов в виде `.txt` файлов в подпапку `prompts/`.
- Каждый файл должен содержать текст промта в обычном текстовом формате.
- Пример: `data/prompts/example.txt`

### 2. Зарегистрируйте промты в `prompts.json`

- В файле `data/prompts.json` регистрируйте все доступные промты в формате JSON.
- Каждый промт должен быть представлен объектом, где:
  - **ключ** — это уникальное имя промта (например, `"example prompt"`),
  - **значение** — объект со следующими полями:
    - `"description"` — краткое описание промта,
    - `"prompt"` — имя файла с текстом промта (например, `"example.txt"`).

**Пример:**
```json
{
  "example prompt": {
    "description": "You have to open README.md",
    "prompt": "example.txt"
  }
}
```

### 3. Используйте примеры

- Файлы `data/prompts.json.example` и `data/prompts/example.txt` служат шаблонами для создания собственных промтов и списков промтов.
- Вы можете скопировать их и изменить под свои нужды.

### 4. .gitignore

- Файл `.gitignore` внутри папки `prompts/` гарантирует, что в системе контроля версий отслеживаются только примеры и необходимые файлы шаблонов.
- Добавляйте реальные промты по мере необходимости, но избегайте фиксации чувствительных данных или информации для production-среды.
